# OpenModularTurrets

Repo for [OpenModularTurrets](https://minecraft.curseforge.com/projects/openmodularturrets) for Minecraft. 

Build turret bases, mount up to four turrets on them and keep your home safe from mobs and unwanted visitors, whether you're online or offline. Open Modular Turrets has long been a popular choice in PvP modpacks, and it is now available on Fabric for Minecraft 1.20.1 and 1.21.1.

## Forge/Neoforge?
You can use the OMT fabric mod on Neoforge/Forge using Sinytra Connector, Connector Extras and ForgifiedFabricApi. Find them here:  
https://www.curseforge.com/minecraft/mc-mods/sinytra-connector  
https://www.curseforge.com/minecraft/mc-mods/connector-extras  
https://www.curseforge.com/minecraft/mc-mods/forgified-fabric-api

## Features

- **14 turrets**, from the disposable item turret and potato cannon to machine guns, grenade and rocket launchers, lasers, railguns and teleporter turrets
- **Turret bases in 5 tiers** that handle targeting, ammo and energy for every turret mounted on them
- **Choose your targets:** hostile mobs, neutral mobs, players, or any combination
- **Trusted players**, so friends can use your base without being shot
- **Upgrades and addons:** range, fire rate, accuracy, efficiency, scattershot, damage amplifier, solar panel, redstone reactor, concealer and more
- **Passive defenses** from Open Modular Passive Defense: hardened blocks, walls, fences and the camouflage trap
- **Generator:** burns furnace fuel and powers adjacent turret bases
- Uses **Team Reborn Energy**, so it works with energy from other Fabric tech mods

## Requirements

- Fabric Loader and Fabric API
  For Neoforge/Forge:
- (Neo)forge + Sinytra Connector + Connector Extras + ForgifiedFabricAPI

## Alpha

This is an alpha release of the Fabric port. Expect bugs, and please report them. Camouflage for turret bases and the camouflage trap is not implemented yet.
